# Spotify おすすめ曲の追加

メインのプレイリストの傾向から曲を選び、メインとは別の「おすすめ用プレイリスト」に入れる。
ユーザーはおすすめ用を聴いて、気に入った曲だけをメインへ移す。メインに直接おすすめ曲を足さない。

## おすすめを追加する

1. **対象を特定する**: ユーザーが名前や URL で指定したプレイリストを `list_playlists` で特定する。
   候補が複数あれば聞く。説明文に `[recommend-for:...]` が付いたものはおすすめ用なので対象にしない
2. **現状を読む**: `get_playlist_tracks` でメインを、`list_recommendations` でおすすめ済みの曲を取得する
3. **傾向をつかむ**: ジャンル・年代・言語・ムード・テンポ感・アーティストの偏りを把握し、1〜3行でユーザーに伝える
4. **候補を挙げる**: 指定がなければ 10 曲。次を守る
   - 実在する曲だけを挙げる。確信の持てない曲は挙げない
   - メイン・おすすめ済みにある曲は挙げない
   - 同じアーティストは 2 曲まで。半分程度はメインにいないアーティストにする
   - ユーザーが方向性 (「もっと新しめ」「インストだけ」等) を指定したら従う
5. **Spotify 上の曲に解決する**: 候補をまとめて `search_tracks` に渡す
   - `exact` / `partial` は採用してよい。ただし partial はカバー・ライブ・リミックスでないか確認する
   - `uncertain` は別名義 (日本語名とローマ字名など) で同じ曲だと判断できるときだけ採用する
   - `none` や不採用の曲は、別の候補を挙げて解決し直し、件数を満たす
6. **追加する**: `add_recommendations` にメインのプレイリストと URI を渡す
7. **報告する**: 追加した曲を「曲名 — アーティスト: おすすめ理由 (1行)」で並べ、おすすめ用プレイリストの URL を添える。
   重複で除外された曲があれば件数を伝える

## メインへ移す

ユーザーが「〇〇と△△をメインに移して」「おすすめの全部移して」などと言ったら:

1. `list_recommendations` でおすすめ用の曲を取得し、ユーザーの指す曲を特定する。曖昧なら確認する
2. `move_to_main` で移す
3. 移した曲と、メインに既にあって削除だけした曲を報告する
